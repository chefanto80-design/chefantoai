# Chef Anto — Portfolio (ChefAntoAI)

Portfolio site for **Chef Anto (Antoanela Alexander)**, Miami chef and builder.
*I am the heart. AI is the brain.*

- Live hub: https://chef-antoai.netlify.app
- Brand home: https://chefanto.com

## What's inside
A single, self-contained `index.html` (HTML + CSS, tiny JS for scroll reveals). No build step.
Showcases: Chef Anto app, chefanto.com, ChefAntoAI hub, Baba by Chef Anto, Dream House, Chef Dogs AI, email system, AI operating system, app lab and brand deck.

## Deploy
Drag this folder into Netlify, or connect this repo to a Netlify site (no build command, publish directory `/`).
